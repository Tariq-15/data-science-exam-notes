Programming & Maths for Data Science

What to memorise for the ICT and maths MCQs, plus the maths that comes up in the interview. Short on purpose.

1Data structures

For each one, know how to write it in Python and whether it is ordered, changeable and allows duplicates.

Watch out

{} is an empty dict. An empty set is set().

Tuple: the facts they test

  • Immutablet[0] = 9 raises TypeError.
  • One item needs a comma(5,) is a tuple. (5) is just the number 5.
  • HashableCan be a dict key or a set item, as long as everything inside it is hashable too.
  • Two methods onlycount() and index().
  • Packing and unpackinga, b = b, a swaps two variables.
  • Faster than a listSmaller in memory. Use it for data that shouldn't change.
  • Inside can changeIn (1, [2, 3]) the list inside is still mutable.

  • Singly linkedEach node points to the next only.
  • Doubly linkedEach node points to the next and the previous.
  • CircularThe last node points back to the head.

Stack and queue

  • Stack (LIFO)list.append() and list.pop(). Used for undo, function calls, DFS and bracket matching.
  • Queue (FIFO)deque.append() and deque.popleft(). Used for BFS, print jobs and task scheduling.
  • DequeAdd or remove at both ends in O(1).
  • Priority queueAlways hands out the smallest item first. Python: heapq, which is a min-heap.
Watch out

list.pop(0) is O(n) because every item shifts left. For a queue, use deque.

Trees, heaps, graphs, hash tables

TraversalOrderResult for this tree
InorderLeft, root, right1 3 6 8 10 14 (sorted)
PreorderRoot, left, right8 3 1 6 10 14
PostorderLeft, right, root1 6 3 14 10 8
Level order (BFS)Row by row8 3 10 1 6 14
  • Binary treeEach node has at most 2 children.
  • BST searchO(log n) when balanced, O(n) when it leans to one side.
  • Tree heightA balanced tree with n nodes is about log₂ n tall.
  • HeapComplete binary tree. In a min-heap the root is the smallest. Push and pop O(log n), peek O(1).
  • Hash tablePowers dict and set. Key → hash → slot, O(1) on average. A collision is two keys landing in the same slot.
  • GraphVertices and edges; directed or undirected, weighted or not. Stored as an adjacency list (sparse) or an adjacency matrix (dense).
  • NumPy arrayOne data type, fixed size, fast maths on the whole array at once.
  • pandas DataFrameA table of labelled columns. Each column is a Series.

2Big-O

Big-O is how the running time (or memory) grows as the input size n grows. Memorise this order, fastest first.

Big-ONameTypical example
O(1)Constantlst[i], d[key], lst.append(x)
O(log n)LogarithmicBinary search, heapq.heappush
O(n)LinearOne loop, x in lst, max(lst)
O(n log n)Linearithmicsorted(lst), merge sort
O(n²)QuadraticNested loops, bubble sort
O(2ⁿ)ExponentialNaive recursive Fibonacci, all subsets
O(n!)FactorialEvery permutation (brute-force travelling salesman)
  • Drop constantsO(2n) is O(n).
  • Keep the biggest termO(n² + n) is O(n²).
  • LoopsOne after another: add. One inside another: multiply.
  • HalvingIf the input halves each step, it's O(log n).
  • Membershipx in list is O(n). x in set or dict is O(1).
  • List endsappend and pop() are O(1). insert(0, x) and pop(0) are O(n).

  • Divide and conquerSplit, solve each part, combine. Merge sort, quick sort, binary search.

4OOP in a few minutes

A class is a blueprint and an object is one thing built from it. __init__ runs when the object is created, and self is that object.

PillarMeaningIn Python
EncapsulationKeep data and the methods that use it together, and hide the insideself._balance is internal by convention, self.__balance is name-mangled
AbstractionShow what it does, hide how it does itABC and @abstractmethod from abc
InheritanceA child class reuses a parent classclass Dog(Animal): and super().__init__()
PolymorphismOne method name, different behaviour in each classDog.speak() and Cat.speak() give different results
  • AttributesInstance attribute (self.name): one per object. Class attribute: shared by every object.
  • super()super().__init__(...) runs the parent's constructor.
  • Method types@classmethod receives the class (cls). @staticmethod receives neither the class nor the object.
  • Dunder methods__init__, __str__ (print), __len__ (len), __eq__ (==).
  • Overriding vs overloadingOverriding: a child redefines a parent method. Overloading (same name, different arguments) is not built into Python.
Check yourself

  1. Which gives an O(1) in check: a list or a set?

    Reveal answer

    A set, because it is a hash table. A list checks items one by one, which is O(n).

  2. What is {}?

    Reveal answer

    An empty dict. An empty set is set().

  3. BFS uses a ___ and DFS uses a ___.

    Reveal answer

    Queue, and stack (or recursion).

  4. What does an inorder traversal of a BST give?

    Reveal answer

    The values in sorted order.

  5. Can (1, 2) be a dict key? What about [1, 2]?

    Reveal answer

    The tuple can. The list can't, because it is mutable and so unhashable.

  6. What is quick sort's worst case, and when does it happen?

    Reveal answer

    O(n²), when the pivot is always the smallest or largest item.

  7. Dog redefines speak() from Animal. Which pillar is that?

    Reveal answer

    Polymorphism, done by method overriding.

5Maths: what to prepare

There are two kinds: quick arithmetic for the admission MCQs, and statistics and probability, which also come up in the interview.

Admission-test maths

Question typeFormula or trick to memorise
Percentagex% of y = xy/100. A change of a% then b% gives a + b + ab/100 overall.
Ratio and proportionSplit N in a : b → Na/(a + b) and Nb/(a + b). If a : b = c : d then ad = bc.
Profit and lossProfit % = (SP − CP) / CP × 100. Discount is taken off the marked price.
Simple and compound interestSI = P·R·T / 100. A = P(1 + R/100)ⁿ, and CI = A − P.
AverageAverage = sum ÷ count, so sum = average × count. Use that when someone joins or leaves.
Time and workA takes a days, B takes b days → together ab / (a + b) days.
Speed, distance, timed = s × t. 1 km/h = 5/18 m/s. Same distance at x and y → average speed 2xy / (x + y).
AgesLet x be the present age, shift by the years given, and solve the equation.
Number seriesCheck the differences, then the differences of those, then ratios. Look for squares, cubes, primes and n(n + 1).
LCM and HCFFor two numbers, HCF × LCM = a × b.
Equationsx = (−b ± √(b² − 4ac)) / 2a. Sum of roots = −b/a, product = c/a.
Indices and logsaᵐ·aⁿ = aᵐ⁺ⁿ and a⁰ = 1. log(ab) = log a + log b, log(aⁿ) = n·log a, logₐ a = 1.
MensurationCircle πr² and 2πr. Triangle ½·b·h. Rectangle l·b. Cylinder πr²h. Sphere 4/3·πr³.
Tip

When the algebra is slow, put each answer option back into the question. In an MCQ, one of them has to fit.

Data-science maths

TopicWhat they askMemorise
Mean, median, modeWhich one to use when there are outliers?The median ignores outliers. With an even count, the median is the average of the two middle values.
Variance and SDHow spread out is the data?σ² = Σ(x − μ)² / n. A sample divides by n − 1. SD = √variance.
ProbabilityDice, coins, cards, balls in a bagP = favourable / total. P(not A) = 1 − P(A). Independent: P(A and B) = P(A)·P(B).
Conditional and Bayes“Given that…”P(A | B) = P(A ∩ B) / P(B). Bayes: P(A | B) = P(B | A)·P(A) / P(B).
Permutations and combinationsArrange or choose?nPr = n! / (n − r)!, where order matters. nCr = n! / (r!(n − r)!), where it doesn't.
Normal distributionHow unusual is a value?z = (x − μ) / σ, and the 68–95–99.7 rule.
CorrelationHow strong is a straight-line link?r runs from −1 to 1. Correlation is not causation.
Hypothesis testingWhat does a p-value mean?The chance of data this extreme if H₀ were true. p < 0.05 → reject H₀.
Linear algebraVectors and matricesDot product a·b = Σaᵢbᵢ. (m×n)(n×p) gives m×p. det [[a, b], [c, d]] = ad − bc.
CalculusSlope, gradient descentd/dx xⁿ = nxⁿ⁻¹. Gradient descent steps against the gradient to make the loss smaller.
Check yourself: test-style maths

  1. A price rises 20%, then falls 20%. What is the overall change?

    Reveal answer

    −4%. 20 − 20 + (20 × −20)/100 = −4.

  2. Compound interest on Tk 10,000 at 10% a year for 2 years?

    Reveal answer

    Tk 2,100. 10,000 × 1.1² = 12,100.

  3. Bought for 800, sold for 1,000. Profit %?

    Reveal answer

    25%. 200 / 800 × 100.

  4. A finishes a job in 10 days and B in 15. How long together?

    Reveal answer

    6 days. 10 × 15 / (10 + 15).

  5. 60 km/h there and 40 km/h back. Average speed?

    Reveal answer

    48 km/h, not 50. 2 × 60 × 40 / (60 + 40).

  6. 2, 6, 12, 20, 30, ?

    Reveal answer

    42. The pattern is n(n + 1), so the next is 6 × 7.

  7. HCF is 6, LCM is 36, and one number is 12. What is the other?

    Reveal answer

    18. 6 × 36 / 12.

  8. Solve x² − 5x + 6 = 0.

    Reveal answer

    x = 2 or x = 3, because it factors as (x − 2)(x − 3).

Check yourself: data-science maths

  1. Mean, median and mode of 2, 3, 3, 5, 7, 10?

    Reveal answer

    Mean 5, median 4 (the average of 3 and 5), mode 3.

  2. Two dice are rolled. P(sum = 7)?

    Reveal answer

    6/36 = 1/6.

  3. How many ways can you choose 3 people from 5?

    Reveal answer

    ⁵C₃ = 10.

  4. A bag has 3 red and 2 blue balls. Draw 2 without putting the first back. P(both red)?

    Reveal answer

    3/5 × 2/4 = 3/10.

  5. μ = 70 and σ = 10. What is the z-score of 85?

    Reveal answer

    (85 − 70) / 10 = 1.5.

  6. det [[1, 2], [3, 4]]?

    Reveal answer

    1·4 − 2·3 = −2.

  7. What is the slope of 3x² + 2x at x = 1?

    Reveal answer

    The derivative is 6x + 2, so 8.

  8. log₂ 64?

    Reveal answer

    6, because 2⁶ = 64.
