Databases & SQL

Keys, SQL commands, joins, normalisation and ACID. Every query here runs in Python's built-in sqlite3.

1Database basics

  • DBMSSoftware that stores and manages a database: MySQL, PostgreSQL, Oracle, SQL Server, SQLite.
  • RDBMSKeeps data in tables (relations) that are linked by keys.
  • Row / columnRow = record = tuple. Column = field = attribute.
  • Degree / cardinalityDegree: the number of columns. Cardinality: the number of rows.
  • SchemaThe structure: tables, columns, types. An instance is the data at one moment.
  • Why not plain filesA DBMS cuts duplication, keeps data consistent, controls access and lets many users work at once.
KeyMeaning
Primary keyIdentifies each row. Unique and never NULL. One per table
Candidate keyAny column (or set) that could serve as the primary key
Alternate keyA candidate key that wasn't picked as primary
Super keyAny set of columns that identifies rows, even with extra columns
Composite keyA key made of two or more columns
Foreign keyA column that points to a primary key in another table
Unique keyMust be unique, but may allow NULL

  • WHERE vs HAVINGWHERE filters rows before grouping. HAVING filters groups after GROUP BY.
  • AggregatesCOUNT, SUM, AVG, MIN, MAX. COUNT(*) counts every row; COUNT(col) skips NULLs.
  • NULLTest with IS NULL or IS NOT NULL, never = NULL.
  • LIKE% matches any number of characters, _ exactly one. 'A%': starts with A.
  • BETWEEN / INBETWEEN 10 AND 20 includes both ends. IN (1, 2, 3) matches a list.
  • DISTINCT / ORDER BYDISTINCT removes duplicate rows. ORDER BY sorts ascending (ASC) unless you add DESC.
  • ConstraintsNOT NULL, UNIQUE, PRIMARY KEY, FOREIGN KEY, CHECK, DEFAULT.

3Joins

  • INNER JOINOnly rows that match in both tables.
  • LEFT JOINEvery row of the left table, plus matches. No match → NULL.
  • RIGHT JOINThe mirror image: every row of the right table.
  • FULL OUTER JOINEvery row from both tables.
  • CROSS JOINEvery row paired with every row: m × n rows (Cartesian product).
  • SELF JOINA table joined to itself, such as employees and their managers.

4Normalisation

FormRuleRemoves
1NFOne value per cell (atomic), no repeating groupsLists inside cells
2NF1NF, and every non-key column depends on the whole keyPartial dependency on part of a composite key
3NF2NF, and non-key columns depend only on the keyTransitive dependency (A → B → C)
BCNFEvery determinant is a candidate keyAnomalies that survive 3NF
Memorise

Every column depends on the key, the whole key, and nothing but the key: that's 1NF, 2NF and 3NF in one line.

  • AnomaliesInsert: can't add a fact without some other fact. Update: one fact stored in many rows. Delete: removing one fact loses another.
  • DenormalisationAdding some duplication back to make reads faster (data warehouses).

5Transactions and more

ACIDMeaning
AtomicityAll or nothing: a bank transfer either fully happens or doesn't happen at all
ConsistencyEach transaction moves the data from one valid state to another
IsolationTransactions running together don't see each other's half-finished work
DurabilityOnce committed, the change survives a crash
  • ER diagramEntity: rectangle. Attribute: ellipse. Relationship: diamond. Key attribute: underlined.
  • Cardinality1:1 (person–passport), 1:N (teacher–classes), M:N (students–courses, which needs a linking table).
  • IndexSpeeds up reads, like a book's index. Makes writes slightly slower.
  • ViewA saved query that behaves like a virtual table.
  • Stored procedure / triggerA procedure is saved SQL you call by name. A trigger runs by itself on INSERT, UPDATE or DELETE.

Check yourself

  1. Can a primary key be NULL?

    Reveal answer

    No. It must be unique and NOT NULL.

  2. To filter after GROUP BY, use WHERE or HAVING?

    Reveal answer

    HAVING.

  3. Which command removes all rows but keeps the table?

    Reveal answer

    TRUNCATE.

  4. A CROSS JOIN of a 4-row and a 5-row table returns how many rows?

    Reveal answer

    20.

  5. In a LEFT JOIN, what fills the right-side columns when there's no match?

    Reveal answer

    NULL.

  6. Which normal form removes transitive dependency?

    Reveal answer

    3NF.

  7. GRANT and REVOKE belong to which group?

    Reveal answer

    DCL.

  8. What does the A in ACID mean?

    Reveal answer

    Atomicity: all or nothing.

  9. Which pattern matches 3-letter names starting with S?

    Reveal answer

    LIKE 'S__'.
