Digital Logic & Number Systems

Number bases, logic gates, Boolean laws and the basic circuits. Only the parts that turn up as MCQs.

  • Decimal → binaryKeep dividing by 2 and read the remainders from bottom to top.
  • Binary ↔ octalGroup 3 bits from the right: 101 011 → 53.
  • Binary ↔ hexGroup 4 bits from the right: 1101 0110 → D6.
  • Hex lettersA = 10, B = 11, C = 12, D = 13, E = 14, F = 15.
  • n bitsGive 2ⁿ values, from 0 to 2ⁿ − 1.
  • Binary addition1 + 1 = 10 (write 0, carry 1). 1 + 1 + 1 = 11.
Memorise

Powers of 2, from 2⁰ to 2¹⁰: 1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024.

Negative numbers and codes

  • 1's complementFlip every bit.
  • 2's complementFlip every bit, then add 1. This is how computers store negative numbers. −5 in 8 bits: 00000101 → 11111010 → 11111011.
  • Sign bitThe leftmost bit (MSB): 0 = positive, 1 = negative.
  • 8-bit rangeUnsigned 0 to 255. Signed −128 to 127.
  • n-bit signed range−2ⁿ⁻¹ to 2ⁿ⁻¹ − 1.
  • BCDEach decimal digit as its own 4 bits: 59 → 0101 1001.
  • ASCII7-bit, 128 characters. 'A' = 65, 'a' = 97, '0' = 48.
  • Unicode (UTF-8)Covers every script, Bangla included. ASCII is its first 128 characters.

De Morgan: break the bar, change the sign. Also worth knowing: A + A′B = A + B.

  • CombinationalOutput depends only on the current inputs (adders, MUX, decoders).
  • SequentialOutput also depends on what is stored (flip-flops, registers, counters). Uses a clock.
  • Flip-flopStores 1 bit. Types: SR, D, JK, T.
  • Latch vs flip-flopA latch is level-triggered. A flip-flop is edge-triggered.
  • JK and TJK with J = K = 1 toggles. T toggles when T = 1.
  • SR invalid stateS = R = 1.
  • Register / counterA register is a row of flip-flops holding one word. A counter counts clock pulses.
  • K-mapSimplifies expressions: group 1s in blocks of 1, 2, 4 or 8.
Check yourself

  1. Convert 25 to binary.

    Reveal answer

    11001: 16 + 8 + 1.

  2. What is 0x1F in decimal?

    Reveal answer

    31: 1 × 16 + 15.

  3. Binary 110101 in octal?

    Reveal answer

    65: 110 = 6 and 101 = 5.

  4. Which gates are universal?

    Reveal answer

    NAND and NOR.

  5. XOR output when both inputs are 1?

    Reveal answer

    0, because the inputs are the same.

  6. Simplify A + AB.

    Reveal answer

    A (absorption law).

  7. Range of an 8-bit signed number?

    Reveal answer

    −128 to 127.

  8. How many select lines does an 8-to-1 MUX need?

    Reveal answer

    3, because 2³ = 8.

  9. (A + B)′ equals?

    Reveal answer

    A′ · B′ (De Morgan).
