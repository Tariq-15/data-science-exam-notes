Machine Learning Basics

Types of learning, the main algorithms, the workflow, overfitting and the metrics, with pandas and scikit-learn code.

1AI, ML and deep learning

  • ModelA function learned from data that makes predictions.
  • Features and labelFeatures (X) are the inputs. The label or target (y) is what you predict.
  • Data splitsThe training set teaches, the validation set tunes and the test set gives the final score. Common splits: 80/20 or 70/15/15.

Ensembles

Bagging: models trained in parallel on random samples, then they vote (random forest). Boosting: models trained in sequence, each fixing the last one's mistakes (AdaBoost, XGBoost). Stacking: one model combines the others' predictions.

4The workflow

  • Missing valuesDrop the rows or columns, or fill them: mean for numbers, median for skewed numbers, mode for categories.
  • OutliersSpot them with box plots or the IQR rule: below Q1 − 1.5·IQR or above Q3 + 1.5·IQR.
  • EncodingOne-hot (one 0/1 column per category) for unordered categories. Label or ordinal encoding (0, 1, 2) for ordered ones.
  • ScalingNormalisation (min-max) squeezes values to 0–1. Standardisation (z-score) gives mean 0 and SD 1. KNN, SVM and gradient descent need it.
  • Data leakageTest information leaking into training. Fit scalers on the training data only.
  • Imbalanced dataJudge with precision, recall and F1, not accuracy. Fix with resampling (SMOTE) or class weights.
  • Data driftLive data drifts away from the training data, so accuracy falls. Retrain the model.
  • First lookdf.head(), df.info(), df.describe(), df.shape.
  • loc vs ilocloc selects by label, iloc by position.
  • Combinepd.merge() joins like SQL. pd.concat() stacks DataFrames.

5Overfitting and underfitting

ProblemSignsFixes
OverfittingGreat on training data, poor on test dataMore data, a simpler model, regularisation (L1 Lasso, L2 Ridge), cross-validation, pruning, dropout, early stopping
UnderfittingPoor on bothMore features, a more complex model, longer training
  • Bias–variance trade-offLowering one tends to raise the other. Aim for the balance.
  • k-fold cross-validationSplit the data into k parts. Train on k − 1, test on the last one, rotate k times, then average the scores.
  • HyperparametersSet before training: k in KNN, tree depth, learning rate. Tune them with grid search.

6Metrics

MetricFormulaAnswers
Accuracy(TP + TN) / totalHow often is it right? Misleading when classes are imbalanced
PrecisionTP / (TP + FP)Of the predicted positives, how many were right?
Recall (sensitivity)TP / (TP + FN)Of the actual positives, how many did we catch?
F1 score2·P·R / (P + R)Balances precision and recall
SpecificityTN / (TN + FP)Of the actual negatives, how many were cleared?
ROC-AUCArea under the ROC curve0.5 = guessing, 1 = perfect
MAEmean |y − ŷ|Average error size (regression)
MSE, RMSEmean (y − ŷ)², √MSEPunish big errors more
R²1 − SSres / SStotShare of the variance explained; 1 is perfect
Tip

Precision matters when false alarms are costly (spam filter). Recall matters when misses are costly (cancer screening, fraud).

7Neural networks and tools

  • NeuronWeighted sum of the inputs plus a bias, passed through an activation function.
  • ActivationsReLU, max(0, x), for hidden layers. Sigmoid (0 to 1) for a yes/no output. Softmax (probabilities summing to 1) for many classes. Tanh (−1 to 1).
  • TrainingForward pass → loss → backpropagation finds the gradients → gradient descent updates the weights.
  • Epoch / batch / learning rateEpoch: one pass over all the training data. Batch: samples per update. Learning rate: the step size.
  • ArchitecturesCNN: images. RNN/LSTM: sequences and time series. Transformer: attention, the basis of LLMs such as GPT and Claude.
  • NLP termsTokenisation, stop words, stemming and lemmatisation, TF-IDF, embeddings.
  • Big data's 5 VsVolume, velocity, variety, veracity, value.
  • Data typesStructured (tables), semi-structured (JSON, XML), unstructured (images, text, audio).

Check yourself

  1. Predicting a house price: classification or regression?

    Reveal answer

    Regression, because the target is a number.

  2. Is K-means supervised or unsupervised?

    Reveal answer

    Unsupervised (clustering).

  3. Training accuracy 99%, test accuracy 60%. What's wrong?

    Reveal answer

    Overfitting.

  4. TP = 40, FP = 10, FN = 20, TN = 30. Precision and recall?

    Reveal answer

    Precision 40/50 = 0.80. Recall 40/60 ≈ 0.67.

  5. Does random forest use bagging or boosting?

    Reveal answer

    Bagging.

  6. Which metric matters most for cancer screening?

    Reveal answer

    Recall: missing a sick patient is the costly mistake.

  7. What is logistic regression used for?

    Reveal answer

    Classification.

  8. What does PCA do?

    Reveal answer

    Cuts the number of features while keeping most of the variance.

  9. Fill missing values in a skewed column with the mean or the median?

    Reveal answer

    The median: outliers pull the mean.
