Security, Cloud & Abbreviations

Threats and defences, how encryption works, cloud service models, and the ICT abbreviations MCQs love.

1Security basics

  • ConfidentialityOnly authorised people can read the data. Tools: encryption, passwords, access control.
  • IntegrityData isn't changed without permission. Tools: hashing, digital signatures.
  • AvailabilitySystems work when needed. Tools: backups, redundancy, DDoS protection.
  • AAAAuthentication: who are you? Authorisation: what may you do? Accounting: what did you do?
  • Authentication factorsSomething you know (password), have (phone, token) or are (fingerprint). 2FA/MFA uses two or more.

3Defences

  • FirewallLets traffic in and out, or blocks it, by rules. Hardware or software.
  • AntivirusFinds malware by its signature and its behaviour.
  • IDS vs IPSAn IDS detects attacks and raises an alert. An IPS detects them and blocks them.
  • VPNAn encrypted tunnel over the internet. Protects you on public Wi-Fi.
  • PatchingMost attacks use known flaws that were never patched. Keep software updated.
  • BackupsThe 3-2-1 rule: 3 copies, on 2 kinds of media, 1 kept off-site.
  • Least privilegeGive each user only the access they need.
  • HoneypotA decoy system that lures attackers so you can study them.
  • CAPTCHAA test that tells humans and bots apart.
  • Ethical hackingAuthorised attacks (penetration testing) that find weaknesses first. White hat = ethical, black hat = criminal.

4Cryptography

FeatureSymmetricAsymmetric
KeysOne shared secret keyA public key and a private key
SpeedFastSlower
Weak pointSharing the key safelySpeed and key size
ExamplesAES, DES, 3DESRSA, ECC, Diffie-Hellman
  • HashingA one-way, fixed-length fingerprint. The same input always gives the same hash. Used for passwords and integrity checks. SHA-256 is safe; MD5 and SHA-1 are broken.
  • Encryption vs hashingEncryption is two-way: it can be decrypted. Hashing is one-way.
  • Digital signatureA hash of the message encrypted with the sender's private key. Proves who sent it and that nothing changed.
  • CertificatesIssued by a Certificate Authority (CA), linking a public key to a website. HTTPS = HTTP + TLS (SSL is the old name).
  • TermsPlaintext → encryption → ciphertext → decryption → plaintext.
  • Caesar cipherShifts every letter by a fixed amount: ABC → DEF with a shift of 3.

5Cloud computing

  • Deployment modelsPublic (shared, run by AWS, Azure or Google Cloud), private (one organisation), hybrid (a mix), community (organisations with shared needs).
  • Key traitsOn-demand self-service, broad network access, resource pooling, rapid elasticity, measured service (pay as you go).
  • Scalability vs elasticityScalability: can handle growth. Elasticity: grows and shrinks automatically with demand.
  • VirtualisationOne physical machine runs many virtual machines through a hypervisor. Type 1 runs on bare metal (VMware ESXi, Hyper-V); Type 2 runs on an OS (VirtualBox).
  • Serverless (FaaS)You upload functions and the provider runs them on demand (AWS Lambda).
  • Edge computingProcesses data close to where it's produced (IoT devices), cutting delay.

Check yourself

  1. Which malware spreads across a network by itself?

    Reveal answer

    A worm.

  2. Is AES symmetric or asymmetric? And RSA?

    Reveal answer

    AES is symmetric. RSA is asymmetric.

  3. Which part of the CIA triad does a DDoS attack hit?

    Reveal answer

    Availability.

  4. Which is one-way: hashing or encryption?

    Reveal answer

    Hashing.

  5. Is Gmail IaaS, PaaS or SaaS?

    Reveal answer

    SaaS.

  6. What runs containers: Docker or a hypervisor?

    Reveal answer

    Docker. A hypervisor runs virtual machines.

  7. A message is encrypted for Bob with asymmetric encryption. Which key opens it?

    Reveal answer

    Bob's private key.

  8. How do you stop SQL injection?

    Reveal answer

    Parameterised queries (prepared statements), plus input validation.

  9. What does OMR stand for?

    Reveal answer

    Optical Mark Recognition: it reads the bubbles on MCQ sheets.
