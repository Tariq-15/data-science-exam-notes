Computer Architecture & OS

How the CPU, memory and operating system fit together, plus the units and terms that MCQs ask about.

1Inside the computer

  • CPUControl unit + ALU + registers. The “brain”.
  • Control unitDecodes instructions and directs every other part.
  • ALUDoes arithmetic (+, −) and logic (AND, compare).
  • Instruction cycleFetch → decode → execute (→ store the result).
  • RegistersPC: address of the next instruction. IR: the current instruction. MAR: the address to read or write. MDR: the data itself. ACC: holds results.
  • BusesData bus: carries data, both ways. Address bus: carries addresses, CPU → memory only. Control bus: read/write and clock signals.
  • Address bus widthn lines reach 2ⁿ locations. 32 lines → 4 GB.
  • Clock speedCycles per second: 3 GHz = 3 billion cycles a second.
  • Multi-coreSeveral processing units on one chip, running tasks in parallel.
  • Harvard designSeparate memories for data and instructions (microcontrollers, DSPs).
  • GPUThousands of small cores. Built for graphics, now the workhorse of deep learning.

  • Primary memoryRegisters, cache, RAM, ROM. The CPU reaches it directly.
  • Secondary storageSSD, HDD, USB drives, optical discs. Keeps data with the power off.
  • Cache hit / missHit: found in cache. Miss: fetched from RAM. L1 is the smallest and fastest.
  • Virtual memoryDisk space used as extra RAM, moved in pages.
  • SSD vs HDDSSD: flash chips, no moving parts, fast. HDD: spinning platters, cheaper per GB.

3Software basics

InterpreterRuns the program line by line and stops at the first error (Python, JavaScript)
AssemblerAssembly language → machine code

  • System vs applicationSystem software runs the computer (OS, drivers, utilities). Application software does tasks for you (browser, Word, games).
  • Language generations1GL machine code, 2GL assembly, 3GL high-level (C, Java, Python), 4GL (SQL), 5GL (Prolog, AI).
  • FirmwareSoftware kept in ROM or flash, such as BIOS/UEFI.
  • BootingPower on → BIOS/UEFI runs POST (the hardware self-test) → bootloader → OS kernel loads.
  • Open sourceThe code is public (Linux, Python). Proprietary software keeps it closed (Windows).

4Operating system

The OS manages the hardware and gives programs services. The kernel is its core; the shell is how you talk to it (command line or GUI).

  • Jobs of an OSProcess, memory, file and device (I/O) management, plus security and the user interface.
  • Program vs processA program is code on disk. A process is a program that is running.
  • ThreadThe smallest unit of work inside a process. Threads share their process's memory.
  • Context switchThe CPU saves one process's state and loads another's.
  • PreemptiveThe OS can take the CPU away from a process. Non-preemptive: it keeps the CPU until it finishes or waits.

  • DeadlockNeeds all four: mutual exclusion, hold and wait, no preemption, circular wait. Break any one to prevent it.
  • PagingMemory split into fixed-size pages and frames. Segmentation uses variable-size logical segments.
  • Page faultThe page isn't in RAM, so it's loaded from disk. Thrashing: so many page faults that the system mostly swaps.
  • Semaphore / mutexLocks that stop two processes using a shared resource at the same time.
  • File systemsFAT32 (old, max file size 4 GB), NTFS (Windows), ext4 (Linux), APFS (macOS).
Check yourself

  1. Which register holds the address of the next instruction?

    Reveal answer

    PC, the program counter.

  2. Which is volatile: RAM or ROM?

    Reveal answer

    RAM.

  3. What is the fastest memory in a computer?

    Reveal answer

    Registers, then cache.

  4. 1 GB is how many MB?

    Reveal answer

    1024.

  5. Which translates the whole program at once?

    Reveal answer

    A compiler. An interpreter goes line by line.

  6. Name the four conditions for deadlock.

    Reveal answer

    Mutual exclusion, hold and wait, no preemption, circular wait.

  7. Which scheduling gives the lowest average waiting time?

    Reveal answer

    SJF (shortest job first).

  8. How many locations can a 16-bit address bus reach?

    Reveal answer

    2¹⁶ = 65,536.
